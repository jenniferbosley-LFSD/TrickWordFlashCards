# Fundations Trick Words Flashcards (Level 1)

A simple, classroom‑ready flashcard web app for **Fundations Level 1 Trick Words**, designed for first grade students, teachers, and families.

This app allows students to practice Trick Words by unit, with smart retry spacing and a friendly visual interface.

---

## 🌟 Features

* ✅ Official **Fundations Level 1 Trick Words** (Units 2–14)
* ☑️ **Checkbox unit selection** (choose one or multiple units)
* 💾 **Auto‑saves unit selections** (remembers last practice set)
* 🔁 **Smart retry**: missed words reappear **2–4 cards later**
* 🎉 Positive visual feedback for student motivation
* 📱 Works on Chromebooks, iPads, laptops, and smartboards


## 🧠 Instructional Notes

* Use **Select All** for cumulative review
* Use individual units for weekly practice
* Typed words can be added for differentiation
* App works offline after first load

---

Aligned with **Fundations® Level 1 Trick Words Scope & Sequence** (Units 2–14).
